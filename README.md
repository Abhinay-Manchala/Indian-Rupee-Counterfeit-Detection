# Indian Rupee Counterfeit Detection System

## Overview

This project uses Artificial Intelligence and Computer Vision to detect counterfeit Indian ₹100 and ₹500 currency notes using a laptop webcam.

## Features

- Detect ₹100 and ₹500 notes
- Real/Fake classification
- Confidence score
- Real-time webcam detection

## Technologies

- Python
- OpenCV
- TensorFlow
- MobileNetV2
- NumPy
- Pandas
